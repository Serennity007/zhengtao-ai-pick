# 1.3.0 整合说明

此文记录整合基线；当前版本为 **1.3.1**，已补充打开文章后及时保存阅读状态的修复。桌面启动、阅读及完整退出恢复的检查结果见 [1.3.1 验收记录](VALIDATION-1.3.1.md)。

本次将 GitHub fork 的完整阅读器与本地正涛精选的科研源整合为一个独立 Obsidian 插件。名称为「正涛精选」，版本 `1.3.0`，ID `zhengtao-ai-pick`。当前交付为本地构建，尚未发布远端 Release 或上架社区插件目录。

## 整合结果

| 部分 | 1.3.0 行为 |
| --- | --- |
| 插件本体 | 独立安装目录、视图与文章回链，可与原乔木插件分别管理 |
| 阅读引擎 | RSS / Atom、探索、分组置顶、频道状态、收藏、已读、正文与图片缓存 |
| 科研订阅 | 内置 23 个公开源，初装置顶「多智能体与 Agent 记忆」「Agent 研究与工程」 |
| 摘录与保存 | 今日日记、选文摘录、文章笔记、桌面 Markdown / PDF 导出 |
| 其他来源 | 选定的库内 Markdown、播客、视频与兼容服务的远程内容 |
| AI | 读取兼容服务已有的翻译／改写；个人 RSS 展示原文或摘要 |

科研目录包含 arXiv cs.MA、LLM Agents、Agent Memory、Zep、Simon Willison、Lilian Weng 等源。目录选择与分组不代表论文质量评分。此版本没有独立模型接口、本机摘要生成、论文相关性排序或自动选题算法。

## 一次性状态整合

首次启动且自己的 `data.json` 不存在时，插件自动读取同库两个前身的数据，通过 `createIntegratedState()` 转换并立即保存。后续以新插件自己的数据为准，不重新导入、不重新种入已删除的源，也不持续同步两套插件。科研预设按新分组组织；其他自定义源和原分组数据保留。

| 数据 | 处理方式 |
| --- | --- |
| 旧 RSS 订阅与分组 | 保留可用数据，按地址处理重复订阅；补入缺少的科研源 |
| 已读与收藏 | 合入新状态，保留可用正文 |
| 文章快照与笔记路径记录 | 保留可用记录，供新插件阅读与归档使用 |
| 原插件数据文件 | 保持原样，供回滚使用 |
| 已有笔记 URI | 保持原样，不批量改写笔记 |
| 管理员令牌、邀请码、收录客户端密钥 | 不复制；需要使用时在新插件单独配置 |

迁移不会让旧链接自动改由新插件处理。`obsidian://qiaomu-ai-rss` 链接继续依赖原乔木插件；新摘录和日记链接使用 `obsidian://zhengtao-ai-pick`，依赖新插件与相应文章快照。

源码包与安装三件套只分发程序和公开目录。`data.json`、私有订阅 URL、迁移备份、服务凭据与个人笔记留在本地。

## 缓存与刷新

个人源在选中频道时按缓存年龄更新，5 分钟内的缓存可复用，刷新按钮强制获取。自动批次最多刷新 20 个 RSS 源，以最多 3 个请求并发执行；插件不注册定时轮询。

每个 RSS 保留最多 50 篇文章，最近打开的正文缓存最多 40 篇。收藏和摘录回链使用的快照单独保存。来源只给摘要时无法凭空补足全文；刷新失败会保留旧文章。公开源的可用性由各提供方决定，23 个目录项不代表每次都能同时取得内容。

分组置顶最多 50 个。旧数据存在超限、重复或失效 ID 时，新版在加载时归一化；重命名合并与别名合并会把置顶映射到保留的分组，删除分组会删除对应置顶。

已读标记沿用阅读引擎最多 5,000 项的保留边界。轻量版旧标记没有来源 ID，迁移时会为活跃源展开匹配标记，因此迁移后的标记数量可能大于原数；长期阅读仍会按引擎上限淘汰。无法无损转换的旧来源标识、或不同服务的远程资产混合会停止迁移，保留原文件，避免悄悄关联到错误文章或服务。

## 安装与回滚

在仓库执行 `npm ci`、`npm run check`，将生成的 `main.js` 与 `manifest.json`、`styles.css` 放入 `<库>/.obsidian/plugins/zhengtao-ai-pick/`，再在第三方插件设置启用「正涛精选」。不要覆盖 `qiaomu-ai-rss` 目录。

本地安装脚本 `npm run install:local -- --vault <绝对库路径> --backup <库和源码之外的新备份目录>` 默认只预览迁移计数。关闭 Obsidian 后加 `--apply` 才安装、备份并更新启用清单；脚本保留乔木插件以支持旧回链，停用旧轻量版，旧数据文件不改动。安装包不含个人数据。已有整合版数据时，升级仅替换程序文件，不重新迁移。

回滚时关闭新插件，重新启用旧版。旧数据仍在原位置；新插件产生的后续阅读状态、收藏与回链不会写回旧版。保留新插件数据可再次启用整合版。删除新数据会使依赖其快照的新回链失效，已写入笔记的文字和导出文件仍保留。
