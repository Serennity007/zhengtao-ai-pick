# 科研阅读流程

## 1.8.0：阅读材料范围与论文入口

文章开头的「阅读材料」面板说明当前显示的是订阅源内容、来源描述、源标注的摘要、已有译文／改写，还是库内笔记副本。新抓取的个人订阅会记录实际选用的 RSS／Atom 字段和是否超过 100,000 字符而被本地截断。来源声明正文也不能证明等同于网站全文；旧缓存与没有这类元信息的远程内容显示完整度未核验。

面板保留可用的「打开原文」入口；如果新订阅条目没有真实文章链接，不会把订阅地址回退显示为原文。只识别出一个明确 arXiv／DOI 标识时提供论文页面，arXiv 另有 PDF 链接。多篇论文、超出保守扫描上限或没有可识别链接时不猜测目标。链接规则复用同论文聚合；[arXiv 官方说明](https://info.arxiv.org/help/api/user-manual.html#3323-links)列出论文页面和 PDF 的链接形式。

新建科研卡片记录 `content_scope` 和 `content_truncated`。无法判断截断情况时后者为空，不用 `false` 暗示旧内容完整。卡片和普通新 Markdown 导出包含同一范围说明，库内笔记的普通复制导出保持原内容。重复打开已有卡片不重写读者已填写的内容；1.7.0 的旧卡片保持原样。

这些操作只使用现有内容与明确标识。点击外链才交给外部页面，插件不额外抓取网站全文、不自动下载或解析 PDF，不调用模型。个人订阅下次按原有策略刷新时补齐元信息，升级不会为了补字段重新抓取所有订阅。

1.8.0 验证：416 项插件测试及 8 项服务端测试通过，类型检查和构建通过。桌面实际看到旧快照的未知范围、新 Atom 摘要标记及论文／PDF 入口；创建 Agent Memory 示例卡片并在阅读模式核对范围属性及提示。覆盖解析边界、旧数据兼容、模式切换、链接安全、公众号单一原文入口与普通导出；未把外链可用性等同于已读取 PDF。

## 1.7.0：科研阅读卡片

打开一篇文章后，从右上角更多菜单选择「保存科研卡片」，或运行同名命令。默认保存在「文章保存目录/科研卡片」（初始为 `正涛精选/文章/科研卡片`）。保存成功后可以打开新笔记；再次执行命令会打开同一文章、同一阅读模式已有的卡片。普通文章笔记和科研卡片分别记录路径，库内重命名或移动后仍可打开。

属性包含原始标题、来源、原文链接、创建时间、来源提供的发布时间、明确的 arXiv／DOI 标识、状态 `to-review`、当前队列命中关键词和阅读模式。没有标识时保留空数组；不联网推断标识或补猜元数据。研究问题、方法、主要发现、局限、对自己研究的启发是待填写的模板栏目，不自动形成论文结论。

卡片附带当前模式的阅读材料和「返回阅读器」回链。先保存独立文章快照，再创建笔记；普通正文缓存清空、来源退订后仍可按回链阅读快照。首次快照保存失败时不会创建卡片；文件已经创建而设置写入失败时，只重试设置以避免重复文件。库内笔记来源会去除复制材料开头的旧属性区，保留原文件不变。

材料可能只有 RSS 摘要、来源解读或被截断的正文，不表示已读取论文 PDF。卡片提示读者核对原论文后填写结论。旧数据不重新迁移，不覆盖现有文章笔记；新增快照和笔记仅保存在当前库。

卡片按来源身份及阅读模式分别记录，两个远程服务使用相同文章 ID 时也不互相打开旧卡片。跨服务的旧快照可以继续阅读，禁止把其 ID 发往当前服务重新加载。多个阅读分栏同时保存时串行检查现有卡片，避免重复创建。

1.7.0 验证：345 项插件测试及 8 项服务端测试通过，类型检查与构建通过。桌面从文章菜单实际创建 Gossip Agents 科研卡片，命令再次执行打开已有文件，阅读模式显示元数据与待填写栏目，点击回链恢复原文。覆盖快照写入失败回滚、建文件后的设置重试、退订后保留原文、来源隔离及双分栏并发回归。

## 1.6.0：同论文聚合

普通阅读列表及今日科研队列会把明确指向同一论文的文章显示为一个可展开的论文组，每篇解读仍有独立的阅读入口、来源和已读状态。先执行当前来源、未读／收藏和关键词过滤，再对当前显示范围分组；键盘前后篇继续沿用原列表顺序。原始订阅、文章 ID、正文与快照不改写、不删除。

只读取原文链接、原始正文及摘要中的明确 HTTP(S) 论文链接，校验精确主机。支持 arXiv abstract／PDF／HTML 链接去版本号，以及 DOI 大小写和跟踪参数归一；明确的 arXiv DOI 可归一为 arXiv。不会根据相似标题、翻译或模型改写推断同一论文，也不会跨查普通出版 DOI 与 arXiv 的关系。

一篇文章只有一个去重后的明确论文标识时才参与聚合。综述引用多个不同标识、正文超过扫描大小或链接数量上限时，保守保持为独立文章，避免误把多篇论文合并。没有识别到标识不表示文章没有相关论文。

1.6.0 验证：313 项插件测试及 8 项服务端测试通过，类型检查与构建通过。现有缓存中识别到 3 个论文组、7 篇文章；桌面实际展开研究分组中的同论文条目、打开其中一个来源，另一个来源仍保持未读。未修改原始文章或跨来源同步已读。

## 1.5.0：今日科研队列

使用命令「正涛精选：今日科研队列」，或点击阅读器筛选栏中的列表勾选图标。

选择多智能体记忆、Agent 工作流或长期规划专题，也可自定义逗号分隔的中英文关键词和排除词。任一关键词命中标题或摘要即可入选，排除词命中则跳过；已读、无有效日期、超出时间范围或明显来自未来的条目不入选。按命中词数及发布时间排序，并执行每个来源和总体的数量上限。点击「保存规则」后生效。

默认最近 7 天、最多 10 篇、每个来源最多 2 篇。仅处理个人订阅已经缓存的文章，不会读取其他笔记或调用模型；点击「刷新订阅」才显式刷新最久未尝试的至多 20 个源，沿用已有网络并发与失败缓存策略。空队列表示当前缓存没有匹配内容，不保证每日必有足够文章。

「稍后读」首版支持个人 RSS 文章，保存独立正文快照，不受筛选规则、时间范围和最近正文缓存淘汰影响。文章保存后，即使取消来源订阅，仍可从稍后读打开快照。移出稍后读仅移除该清单项，不删除原始文章、收藏或笔记。保存快照可能只有来源提供的摘要或已截断的正文，完整度仍以原文为准。

旧版升级自动补齐空队列设置和空稍后读列表，不重新导入订阅，不改已读与收藏。设置及清单写入失败会恢复原状态，可重试；切换兼容服务地址也保留规则与快照。

1.5.0 验证：280 项插件测试及 8 项服务端测试通过，类型检查与构建通过。桌面实际打开队列、保存一篇个人 RSS 文章到稍后读，并从快照打开正文；退订后刷新保护、非个人来源拒绝、失败回滚和并发保存均有针对性回归测试。
