- 使用独立插件 ID `zhengtao-ai-pick`、名称「正涛精选」及自己的文章回链，不再覆盖乔木插件或注册其旧协议。

- 保留分组、探索目录、收藏、已读、正文缓存、摘录、日记、笔记归档、桌面导出、本地 Markdown 与媒体阅读能力。
- 通过 `createIntegratedState()` 一次性整合旧订阅、已读、收藏及文章快照；保留旧数据和笔记 URI，迁移不复制管理员令牌、邀请码或收录客户端凭据。
- 修复超出 50 个置顶后加载失败、重命名合并丢失置顶及别名合并留下失效 ID；恢复旧列表时去重、过滤并限于 50 个有效置顶。
- 移除文档中的上游覆盖式安装入口、二维码及联系误导，保留上游 GPL 与第三方版权声明。

个人 RSS 提供原文或摘要，远程 AI 版本仍来自服务已有内容。此版本没有独立模型生成、论文评分或自动选题算法。个人源缓存有效期为 5 分钟，自动批次最多 20 个源、3 个并发；每源最多 50 篇，最近正文缓存 40 篇，无定时轮询。

安装与回滚、迁移的数据范围见 [整合说明](INTEGRATION-1.3.0.md)。
