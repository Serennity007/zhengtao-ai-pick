# 正涛精选 1.8.0

- 阅读器在文章开头显示材料范围，区分新抓取订阅的正文／描述／摘要字段、空内容与本地截断；旧缓存明确保持完整度未核验。
- 论文标识唯一且明确时提供论文页面；arXiv 增加 PDF 链接。点击才打开外部页面，不预取或解析 PDF。
- 新科研卡片保存 `content_scope`、`content_truncated` 和范围说明，普通新导出也保留说明；不改写已有笔记。
- 不把缺少文章链接时的 RSS 地址回退当作原文入口，保留原文章 ID 与缓存规则。

## 1.7.0

- 新增「保存科研卡片」命令及文章更多菜单入口，写入来源、明确的 arXiv／DOI 标识、命中主题、阅读模式和创建时间。
- 提供待填写的研究问题、方法、主要发现、局限与研究启发栏目，附当前阅读材料，不自动生成科研结论。
- 先持久化文章快照，再生成独立卡片及本插件回链；普通笔记与卡片映射分开，重复保存打开已有卡片，随库内重命名更新路径。
- 本版本同时包含 1.5.0 的专题队列／稍后读与 1.6.0 的同论文聚合。使用方式见 [科研阅读流程](RESEARCH-WORKFLOW.md)。

## 1.6.0

- 统一 arXiv 版本、PDF 链接及 DOI 大小写，不凭标题推断；含多篇论文或超扫描上限的长文保守保持独立。
- 不改原始文章、收藏、快照或已读数据；键盘导航仍按原列表顺序。

## 1.5.0

- 内置多智能体记忆、Agent 工作流及长期规划专题，可保存自定义规则，显示关键词命中原因。
- 新增持久化「稍后读」，独立保存正文快照；来源缓存过期或取消订阅不会删除快照。规则与稍后读保存在本地，不调用模型。

## 1.3.0 整合基线

本地整合构建，尚未发布至远端 Releases 或 Obsidian 社区插件目录。

- 使用独立插件 ID `zhengtao-ai-pick`、名称「正涛精选」及自己的文章回链，不再覆盖乔木插件或注册其旧协议。
- 合入完整 RSS 阅读器与本地独立版的 23 个科研源。初装置顶「多智能体与 Agent 记忆」「Agent 研究与工程」。
- 保留分组、探索目录、收藏、已读、正文缓存、摘录、日记、笔记归档、桌面导出、本地 Markdown 与媒体阅读能力。
- 通过 `createIntegratedState()` 一次性整合旧订阅、已读、收藏及文章快照；保留旧数据和笔记 URI，迁移不复制管理员令牌、邀请码或收录客户端凭据。
- 修复超出 50 个置顶后加载失败、重命名合并丢失置顶及别名合并留下失效 ID；恢复旧列表时去重、过滤并限于 50 个有效置顶。
- 移除文档中的上游覆盖式安装入口、二维码及联系误导，保留上游 GPL 与第三方版权声明。

个人 RSS 提供原文或摘要，远程 AI 版本仍来自服务已有内容。此版本没有独立模型生成、论文评分或自动选题算法。个人源缓存有效期为 5 分钟，自动批次最多 20 个源、3 个并发；每源最多 50 篇，最近正文缓存 40 篇，无定时轮询。

安装与回滚、迁移的数据范围见 [整合说明](INTEGRATION-1.3.0.md)。
