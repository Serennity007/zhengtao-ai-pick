# 正涛精选 · Zhengtao AI Pick

面向科研阅读的 Obsidian 插件，整合完整 RSS 阅读器、23 个科研订阅源与 9 个国内公众号精选。当前整合版为 **1.7.0**，插件 ID 为 **`zhengtao-ai-pick`**，可与乔木插件分别安装。

本项目基于 [Qiaomu AI RSS](https://github.com/joeseesun/qiaomu-ai-rss)，原作者为向阳乔木（[@joeseesun](https://github.com/joeseesun)），沿用 **GPL-3.0-only**。独立化改动见 [FORK.md](FORK.md)。

## 功能

- **专题阅读队列**：按研究关键词、排除词和最近天数筛选缓存中的未读文章，限制总数及每个来源的数量；内置多智能体记忆、Agent 工作流、长期规划专题，可自定义。稍后读单独保存正文快照。见 [科研阅读流程](docs/RESEARCH-WORKFLOW.md)。
- **同论文聚合**：阅读列表及今日队列按明确的 arXiv ID／DOI 折叠同一论文的不同文章，保留每篇原文、来源和独立已读状态；不凭相似标题合并。
- **科研阅读卡片**：从当前文章的更多菜单或「保存科研卡片」命令创建库内笔记，保存来源、论文标识、命中主题与本地快照回链；提供待填写的问题、方法、结论、局限和启发栏目，重复保存打开已有卡片。
- **科研订阅**：内置 arXiv cs.MA、LLM Agents、Agent Memory，以及 Zep、Lilian Weng、Simon Willison 等 23 个公开源。初装置顶「多智能体与 Agent 记忆」「Agent 研究与工程」两个分组。
- **国内公众号精选**：PaperWeekly、AINLP、机器之心、AI 大模型应用实践、AI 科技评论、Datawhale、PaperAgent、夕小瑶科技说、新智元。首次安装加入「国内公众号精选」分组；已有用户可在探索页点击「添加国内精选」，或运行同名命令批量补充。已订阅账号保留原名称和分组，不重复添加已知旧地址。
- **个人订阅管理**：添加 RSS / Atom、分组、重命名、取消订阅、OPML 导入与导出；分组可置顶为顶层频道，最多 50 个。
- **完整阅读器**：双栏与专注阅读、频道切换、加载历史文章、搜索当前列表、未读与收藏筛选、阅读主题及字体设置。常规阅读器的各频道保存列表、阅读位置及筛选条件；实验室采集页不承诺恢复当前文章。
- **收藏与归档**：保留收藏正文，选文摘录到今日日记或当前笔记，保存文章为库内笔记；桌面端支持 Markdown / PDF 导出。新生成的内部回链使用 `obsidian://zhengtao-ai-pick`。
- **本地与媒体**：阅读选定的库内 Markdown 文件夹，使用图片缓存，播放来源提供的播客音频与 YouTube 媒体。
- **兼容远程内容**：保留探索订阅、远程精选、播客及已有翻译／改写版本的读取能力。

个人 RSS 展示来源提供的原文或摘要。阅读器读取远程服务已有的翻译和改写，**没有独立模型接入或本机 AI 生成能力**。本次整合没有新增论文相关性评分、自动选题或科研摘要算法；科研聚合与主题分组可直接使用。

## 安装

需要 Obsidian **1.13.0 或更新版本**。当前整合版为 1.7.0，源码可从本仓库获取；尚未发布到 Releases 或 Obsidian 社区插件目录。

已有本地安装包时，可直接使用其中构建好的三件套。也可以从仓库构建：

```sh
git clone https://github.com/Serennity007/zhengtao-ai-pick.git
cd zhengtao-ai-pick
npm ci
npm run build
```

使用随附的源码包时，在解压后的 `zhengtao-ai-pick` 目录运行 `npm ci` 和 `npm run build` 即可。

1. 在库的配置目录下创建 `plugins/zhengtao-ai-pick/`，默认完整路径为 `<库>/.obsidian/plugins/zhengtao-ai-pick/`。
2. 将构建目录的 **`main.js`、`manifest.json`、`styles.css`** 放入该目录。
3. 在 Obsidian「设置 → 第三方插件」启用 **正涛精选**，通过侧边栏望远镜图标或命令面板打开阅读器。

请使用本项目的三件套。旧文档中的上游安装目录、上游 Releases 和覆盖乔木插件的方式不适用于整合版。

## 迁移与回滚

首次启动且尚无自己的 `data.json` 时，插件会读取同库 `qiaomu-ai-rss` 和 `zhengtao-picks` 的本地数据，通过 `createIntegratedState()` 一次性合并订阅、已读、收藏及文章快照，并加入科研订阅。保存后以新插件自己的数据为准，不会每次启动重新种入订阅。整合不会改写旧插件数据或已有笔记 URI，也不会复制管理员令牌、邀请码、收录客户端密钥等服务凭据。功能与迁移范围见 [1.3.0 整合说明](docs/INTEGRATION-1.3.0.md)。

旧 `obsidian://qiaomu-ai-rss` 回链由原乔木插件处理；整合版使用自己的协议。需要回滚时，关闭新的正涛精选插件，重新启用旧版即可。旧插件数据保持原样；整合后产生的收藏、阅读状态和新回链保存在新插件中，不会反向写回旧版。

源码与安装包只包含程序和公开目录。个人 `data.json`、私有订阅地址、备份及凭据不应放入源码包或提交仓库。

## 使用与缓存

点击频道名称切换分组，使用 **+** 添加订阅或进入探索页。搜索覆盖当前加载的列表；读取更早内容需要进入对应频道继续加载。来源只提供摘要时，可打开原文。

个人订阅缓存的有效期为 **5 分钟**。进入频道时按过期情况获取内容，刷新按钮强制更新；自动批次最多刷新 **20 个源**，最多 **3 个并发请求**。插件不注册定时轮询。每个 RSS 最多保存 **50 篇**，最近打开的正文缓存最多 **40 篇**；收藏及摘录回链使用的文章快照单独保留。刷新失败会保留已有文章，源的可用性和全文长度由其提供方决定。

国内精选使用公开的 BestBlogs 公众号 RSS，保留微信原文链接。精选指账号选择，文章仍按发布时间展示；较长正文可能受缓存上限截断，可打开原文继续阅读。账号清单、实测和数据处理方式见 [国内公众号精选](docs/DOMESTIC-WECHAT.md)。

## 隐私与服务

订阅地址、已读、收藏和快照保存在当前库的插件数据中。个人 RSS 请求直接访问各源；远程精选、翻译、改写及在线目录访问配置的服务，默认地址为 `https://rss.qiaomu.ai`。图片和播放媒体会联系对应的内容主机。同步库配置时，你的同步服务也可能复制插件数据。

常规阅读不提交库内笔记或请求新 AI 生成。实验室的链接收录属于可选远程服务功能，需要另行启用及验证；迁移不继承其凭据。详情见 [隐私与网络说明](docs/PRIVACY.md)。

```sh
npm ci
npm run check
npm run dev
```
